# Sprint_7

Финальный проект седьмого спринта курса «Инженер по тестированию» (Яндекс Практикум): API-автотесты для учебного сервиса «Яндекс Самокат» на `requests` и pytest с Allure-отчётом.

## Стек

- Python 3
- pytest
- requests
- Faker — генерация тестовых данных
- Allure (`allure-pytest`)

## Структура проекта

```
Sprint_7/
├── src/
│   ├── urls.py               # базовый URL и эндпоинты API
│   ├── messages.py           # ожидаемые тексты ошибок
│   └── helpers.py            # генерация данных, регистрация и удаление курьера
├── tests/
│   ├── test_create_courier.py  # TestCreateCourier — создание курьера
│   ├── test_login_courier.py   # TestLoginCourier — логин курьера
│   ├── test_create_order.py    # TestCreateOrder — создание заказа
│   └── test_get_orders.py      # TestGetOrders — список заказов
└── allure_results/           # результаты прогона для Allure-отчёта
```

## Покрытые ручки

| Ручка | Метод | Тесты |
|-------|-------|-------|
| `/api/v1/courier` | `POST` | Успешное создание, дубликат курьера, отсутствие `login` / `password` (параметризация), занятый логин |
| `/api/v1/courier/login` | `POST` | Успешный логин возвращает `id`, неверный логин / пароль (параметризация), отсутствие поля, несуществующий курьер |
| `/api/v1/orders` | `POST` | Создание заказа с цветом `BLACK`, `GREY`, обоими и без цвета (параметризация), ответ содержит `track` |
| `/api/v1/orders` | `GET` | Ответ содержит список заказов, несуществующий `courierId` возвращает 404 |

Созданные в тестах курьеры удаляются после проверки через `DELETE /api/v1/courier/:id`.

## Запуск

1. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install pytest requests faker allure-pytest
   ```

2. Запустите тесты с сохранением результатов для Allure:

   ```bash
   pytest tests --alluredir=allure_results
   ```

3. Откройте отчёт (нужен установленный [Allure CLI](https://allurereport.org/docs/install/)):

   ```bash
   allure serve allure_results
   ```

## Задание

Протестируй ручки: проверь, что они корректно работают и возвращают нужные ошибки.

### Создание курьера

Проверь, что:

- курьера можно создать;
- нельзя создать двух одинаковых курьеров;
- чтобы создать курьера, нужно передать в ручку все обязательные поля;
- запрос возвращает правильный код ответа;
- успешный запрос возвращает `{"ok": true}`;
- если одного из полей нет, запрос возвращает ошибку;
- если создать пользователя с логином, который уже есть, возвращается ошибка.

### Логин курьера

Проверь, что:

- курьер может авторизоваться;
- для авторизации нужно передать все обязательные поля;
- система вернёт ошибку, если неправильно указать логин или пароль;
- если какого-то поля нет, запрос возвращает ошибку;
- если авторизоваться под несуществующим пользователем, запрос возвращает ошибку;
- успешный запрос возвращает `id`.

### Создание заказа

Проверь, что при создании заказа:

- можно указать один из цветов — `BLACK` или `GREY`;
- можно указать оба цвета;
- можно совсем не указывать цвет;
- тело ответа содержит `track`.

Для тестов создания заказа нужно использовать параметризацию.

### Список заказов

Проверь, что в теле ответа возвращается список заказов.

### Код и отчёт

Подготовь код тестов и запушь его в репозиторий. Сгенерируй Allure-отчёт и тоже запушь его.

> Всю папку `target` коммитить не нужно — только отчёт:
>
> ```bash
> # добавляем папку с отчётом Allure; ключ -f нужен, если папка указана в .gitignore
> git add -f ./target/allure-results/.
> git commit -m "add allure report"
> git push
> ```

## Дополнительное задание

> Необязательное: не влияет на оценку за основную часть, но помогает дополнительно попрактиковаться.

Протестируй ещё три ручки.

### Удалить курьера

Проверь, что:

- неуспешный запрос возвращает соответствующую ошибку;
- успешный запрос возвращает `{"ok": true}`;
- если отправить запрос без id, вернётся ошибка;
- если отправить запрос с несуществующим id, вернётся ошибка.

### Принять заказ

Проверь, что:

- успешный запрос возвращает `{"ok": true}`;
- если не передать id курьера, запрос вернёт ошибку;
- если передать неверный id курьера, запрос вернёт ошибку;
- если не передать id заказа, запрос вернёт ошибку;
- если передать неверный id заказа, запрос вернёт ошибку.

### Получить заказ по его номеру

Проверь, что:

- успешный запрос возвращает объект с заказом;
- запрос без номера заказа возвращает ошибку;
- запрос с несуществующим заказом возвращает ошибку.
